## 这一章想让你建立什么

**3-1** 把「记忆」这个词拆开。拆完发现它就是两个动作：

```
写：会话结束 → 决定留下什么 → 存起来
读：会话开始 → 取出来       → 拼进上下文
```

四种策略，**差别 100% 在「写」**，结果天差地别 ——
而两种提取模式之间的全部区别，字面意义上就是一段提示词。
这和实验 2-1 是同一条规律：*压缩质量 ≈ 压缩提示词质量；记忆质量 ≈ 提取提示词质量。*

然后它会撞上一堵提示词修不好的墙：**事实变了怎么办？**
实测四种策略没有一种能处理，原因就藏在一行代码里。
这也正是 mem0、Memobase 这类真实记忆框架为什么长成那样。
