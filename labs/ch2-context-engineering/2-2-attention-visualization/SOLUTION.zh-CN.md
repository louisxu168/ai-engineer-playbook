## 一、实测数据

Qwen3-0.6B（28 层 × 16 头），取最后 4 层所有头的平均，2026-07-29

### basic：「北京 的 天气 怎么样」

```
原始分布：
  ████████████████████████       81.0%  '北京'      ← 汇聚点
  █                               3.0%  '气'
  █                               2.9%  ' 的'
  █                               2.6%  '么'

剔除汇聚点后：
  █████████                      29.4%  '气'       ← 天【气】
  █████████                      28.5%  ' 的'
  ████████                       25.7%  '么'
```

### status_bar：书里 2-7 的场景

```
【A】没有状态栏     轨迹 28.7%   每字密度 0.256%
【B】有状态栏       轨迹 21.1%   每字密度 0.189%
                    状态栏 10.7%  每字密度 0.715%   ← 只有 15 个字

状态栏每字密度 = 轨迹的 3.8 倍
加了状态栏后，轨迹拿到的注意力下降 7.6%
```

### dilution：**没有干净复现**

```
上下文   67 token   针拿到 3.135%
上下文  337 token   针拿到 5.046%     ← 涨了
上下文 1309 token   针拿到 4.133%
```

## 二、注意力汇聚点：最容易误读的东西 ★★

第 1 个 token 拿了 **81%**。

**这和语义无关。** 这是 Transformer 的一个已知副作用，叫
**注意力汇聚点**（attention sink）：模型需要一个「什么都不特别关注」的
默认去处，而第 1 个 token 就承担了这个角色。可以理解成**垃圾桶**。

剔掉它重新归一化之后，语义信号才出来：

```
'气'  29.4%      ← 「怎么样」在关注「天【气】」，这才是对的
' 的' 28.5%
'么'  25.7%
```

> **这是本实验最实用的一课：直接看注意力，第一眼几乎一定会看错。**
>
> 网上很多「注意力热力图」文章不处理汇聚点，于是图上永远是第一个 token 最亮，
> 然后作者会给它编一个语义解释。
>
> **练习 4** 让你亲手验证这一点：把第一个词换成完全不相干的词，
> 看它是不是照样拿 ~80%。

---

## 三、状态栏：书里 2-7 量化复现了 ✅

15 个字的状态栏，**每字吸引的注意力是 112 字轨迹的 3.8 倍**。

而且它**把注意力从原始轨迹上抢走了**：轨迹从 28.7% 掉到 21.1%。

书里的说法是：

> 对照组 A：注意力高度分散，模型在**从原始信息里做统计**
> 对照组 B：注意力**高度集中在状态栏上**，直接用已经算好的结论

**实测支持这个说法**，而且给出了具体倍数。

> **和[实验 2-8](../2-8-system-hint/SOLUTION.zh-CN.md)是一对：**
>
> | | 量的是 | 结果 |
> |---|---|---|
> | 2-6 | **行为** | 0.6B 无状态栏违规 50%，有状态栏 32.5% |
> | 2-8（本实验） | **机制** | 注意力密度差 3.8 倍，且从轨迹转移走了 7.6% |
>
> **两个合起来才完整。** 2-6 告诉你「行为变了」，
> 2-8 告诉你「注意力从哪儿转移到了哪儿」—— 也就是**为什么**变了。

## 四、稀释：没能干净复现，因为变量缠在一起

```
67 token   3.135%
337 token  5.046%     ← 反而涨了
1309 token 4.133%
```

**不单调。** 原因是这个测法里至少有三个效应同时在动：

| 效应 | 方向 | 说明 |
|---|---|---|
| **稀释** | ↓ | token 变多，每个分到的变少 —— 这是我想测的 |
| **距离** | ↓ | 针离问题越来越远，近因效应让权重下降 |
| **汇聚点** | ？ | 第 1 个 token 吃掉的比例本身随长度变化 |

**三个混在一起，就不可能看出单调曲线。**

> **但机制本身是确定成立的**，不依赖这次测量：
> 注意力权重加起来必须等于 1（softmax 的性质），
> 所以 token 越多，**平均每个分到的必然越少**。这是数学，不是经验。
>
> 我测不出干净曲线，是**我的实验设计没控制住变量**，
> 不是这条机制不存在。

**练习 3 给了拆开变量的办法**：把针固定在离问题 N 个 token 的位置，
只改前面填充的长度 —— 这样「距离」就不变了。

## 五、我连续踩的三个测量坑 ★★★

这一节可能比上面所有结论都有用。**每一个坑都会让你得出错误结论，
而且都不会报错。**

### 坑 1：没剔除汇聚点

第一版我直接看注意力，得出「模型最关注『北京』」。

**错的。** 那 81% 是汇聚点，和语义无关。

> **症状**：第一个 token 永远最亮。
> **如果你不知道有汇聚点这回事，你会给它编一个语义解释** ——
> 而且编得出来（「北京是主语嘛」）。

### 坑 2：稀释实验把针放在第 1 个位置

第一版我把「密码是 7391」放在开头，结果三个长度下它都拿 ~78%，
**完全测不出稀释**。

因为**它正好坐在汇聚点上** —— 那 78% 根本不是「它作为关键信息」拿到的。

> 修法：把针放到**中间**。
> **一个测量工具的已知偏差，会伪装成你的实验结果。**

### 坑 3：用关键词匹配 token

status_bar 那一版我是这么写的：

```python
for token_text, w in zip(tokens, weights):
    if key in token_text:      # key = "上限"
        total += w
```

**结果 B 组算出 0.000%。**

因为中文分词把「上限」切成了别的形状，`"上限" in token_text` 永远为假 ——
**匹配不到，就悄悄算成 0**。

修法是用 `return_offsets_mapping=True` 拿到每个 token 的**字符区间**，
按字符位置圈，而不是按文本匹配。

> **症状最可怕的一个坑**：它给出的是 `0.000%`，一个看起来很确定的数字。
> 如果我没觉得「0 太可疑了」，就会得出「状态栏根本没被注意到」这个**完全相反**的结论。

### 坑 4（顺带）：比较长度不等的区间

修好坑 3 之后，A 组 85.7% vs B 组 2.2% —— 看起来状态栏毫无存在感。

但 A 组量的是**整条轨迹**（112 字），B 组量的是**状态栏**（15 字）。
**长的那段总量必然大。**

要比的是**每字密度**。换成密度之后，结论直接反转成 **3.8 倍**。

## 六、一条方法论

四个坑合起来，是同一件事：

> **在你用一个工具去测量之前，先搞清楚这个工具本身有什么偏差。**

- 注意力有汇聚点偏差 → 不剔除就会误读
- 分词会切碎关键词 → 文本匹配会静默失败
- 区间长度不等 → 比总量没有意义

而这四个坑**没有一个会报错**。它们都给你一个看起来很正常的数字。

> 这和[实验 6-1](../../ch6-evaluation/6-1-llm-as-judge/SOLUTION.zh-CN.md)、
> [实验 10-1](../../ch10-multi-agent/10-1-single-vs-multi/SOLUTION.zh-CN.md)
> 是同一条教训：
>
> **测量工具自己的故障，会被记成被测对象的性质。**
>
> 本仓库到现在，这已经是第四次了。

## 七、练习答案

### 练习 1 ⭐ 换一层看

一般规律：**浅层更关注位置和句法**（比如强烈关注前一个 token），
**深层更关注语义**。

改 `LAYERS_FROM_END` 就能验证。**这条你现在能亲眼看到，而不是背下来。**

### 练习 2 ⭐⭐ 看单个头

不同的头在做非常不同的事 —— 有的专门「看前一个 token」，
有的专门「找同类词」，有的几乎只盯着汇聚点。

> **平均之后这些结构全糊掉了。** 所以只看平均热力图，
> 容易得出「注意力就是一团糊」这种过于笼统的印象。

### 练习 3 ⭐⭐⭐ 拆开稀释实验的变量

把针固定在**离问题 N 个 token** 的位置，只改前面填充的长度：

```
[填充 × K][针][固定长度的填充][问题]
            ↑ 距离问题的距离恒定
```

这样「距离」不变，剩下的变化才是稀释。

> **这是本实验最值得做的练习** —— 它教的是**怎么把纠缠的变量拆开**，
> 而这正是实验 2-4 里我改了三版判据才学会的东西。

### 练习 4 ⭐⭐ 验证汇聚点和内容无关

把「北京 的 天气 怎么样」改成「香蕉 的 天气 怎么样」，
第一个 token 应该**照样**拿 ~80%。

> 如果确实如此，你就亲手证明了那 80% 和语义无关 ——
> **而这是本实验第一个、也是最重要的一课。**
