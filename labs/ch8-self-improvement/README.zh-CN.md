# 第 8 章：持续进化

[English](README.md) · **简体中文**

第 3 章教 agent 记**事实**。这一章问一个更难的问题：
它能不能记住**教训**——不在同一个地方栽两次？

## 这一章想让你建立什么

**8-1** 给 agent 三个退款工单，和一个**文档里少写了三条校验规则**的工具。
想发现那三条规则，只能靠撞错误——**而这正是生产环境的真实手感**，
因为文档永远落后于实现。

实测结果**推翻了实验 3-1 的结论**。在 3-1 里，好的提取提示词打败了原样存全部。
在这里，**原样记录赢了失败曲线**——因为原始错误信息里带着那三个合法枚举值，
而「提炼出的教训」把它们抽象掉了，变成了正确但没用的建议
（「要确认枚举的合法取值」），然后 agent 一丝不苟地遵守自己的教训、
造了一个大小写完全规范的标识符，又失败了一次。

规律是：**存事实时，抽象是提纯；存教训时，抽象可能把答案扔了。**
教训里最值钱的部分，往往正是那个看起来"太具体、不该留"的值。

这一章还带着一条比结果更值钱的评测警告：
**「没学会」和「没见过」在指标上长得一模一样**——除非你知道哪条规则是新的。
