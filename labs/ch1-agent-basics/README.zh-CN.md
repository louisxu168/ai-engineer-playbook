## 这一章想让你建立什么

**1-1** 拆掉「Agent」这个词的神秘感。你会发现它就是：

```
loop:
    reply = llm(messages)              # 模型说它想干嘛
    if 没有工具调用: 结束
    for 每个工具调用:
        result = 你的代码去执行(...)     # 模型跑不了，你跑
        messages.append(result)        # 结果塞回去
```

然后通过**故意删掉上下文的某一部分**，看它以什么方式坏掉。四种坏法对应四类真实
线上事故：上下文被截断、工具集成写挂、权限配错、为省 token 丢了 thinking。

**1-2** 换一个角度问：既然模型自带工具（Claude Code 能自己联网搜索），
那你为什么还要自己写循环？

答案不是「哪个更好」，而是**你在交易什么**。同一个问题跑五遍，你会亲眼看到
hosted 模式答得又快又好、但整个过程对你完全不透明；DIY 模式慢很多、
但每一次搜索失败和自我纠正都在你眼前。

两个实验合起来，你应该能回答：**出了问题，我能 debug 哪一个？**

## 跑法

每个实验都是**独立文件夹**，自带全部代码和依赖：

```bash
cd 1-1-context
pip install -r requirements.txt
python3 agent.py            # 先看用法说明
```

不需要 API key —— 会自动用你已装的 Claude Code 或 Codex。
