# 实验 2-2：注意力可视化 —— 把模型打开看一眼

[English](README.md) · **简体中文**

> **你会学到什么**
>
> 1. **注意力汇聚点**（attention sink）：第 1 个 token 吃掉 **81%** 的注意力，
>    而这**和语义无关** —— 这是直接看注意力时最容易误读的地方
> 2. 剔掉它之后，才看得见真正的语义分布
> 3. 书里 2-7 的说法**量化复现了**：状态栏的**每字注意力密度是轨迹的 3.8 倍**
> 4. 一个没能复现的：注意力稀释**不是单调的**，因为有三个效应缠在一起
>
> **怎么学**：这是本仓库唯一一个**真正打开模型**的实验。
>
> **需要多久**：25 分钟（含安装）。
>
> ⚠️ **本仓库唯一需要重量级依赖的实验**（约 2.5GB）。不装也没关系。

## 第 1 步：看一眼注意力（5 分钟）

```bash
.venv-attn/bin/python agent.py basic
```

句子是「北京 的 天气 怎么样」，看最后一个 token 往回关注谁。

### 🤔 先猜

你觉得「样」最关注哪个词？

### 👀 你会看到

```
  ████████████████████████       81.0%  '北京'
  █                               3.0%  '气'
  █                               2.9%  ' 的'
```

**「北京」拿了 81%。**

### 💡 学到什么 ★

**这不是因为「北京」语义上最重要 —— 这是「注意力汇聚点」。**

Transformer 里第 1 个 token 会系统性地吸走大量注意力，**几乎与内容无关**。
可以理解成模型的「垃圾桶」：当它不知道该看哪时，就把权重倒在那里。

程序会自动剔掉它再归一化，然后你看到的才是语义分布：

```
  剔除汇聚点后的分布：
  █████████                      29.4%  '气'      ← 天【气】
  █████████                      28.5%  ' 的'
  ████████                       25.7%  '么'
```

**「怎么样」确实在关注「天气」** —— 但这个信号被汇聚点压住了，不剔掉根本看不见。

> **这是本实验最实用的一课：**
> **直接看注意力，第一眼几乎一定会看错。**
>
> 网上很多「注意力热力图」文章不处理汇聚点，于是图上永远是第一个 token 最亮 ——
> 然后作者会给它编一个语义解释。

## 第 2 步：注意力稀释（5 分钟）

```bash
.venv-attn/bin/python agent.py dilution
```

把同一条「密码 是 7391」放进 67 / 337 / 1309 token 的上下文，
看它拿到的注意力。

### 👀 你会看到

**三个数大概率不是单调下降的。** 我也没测出干净的曲线。

### 💡 学到什么

**这个测法里至少有三个效应缠在一起：**

| 效应 | 方向 |
|---|---|
| 稀释 —— token 变多，每个分到的变少 | ↓（我想测的） |
| 距离 —— 针离问题越来越远 | ↓（近因效应） |
| 汇聚点 —— 第 1 个 token 吸走一大块，占比还随长度变 | ？ |

**三个混在一起，单调性就没了。**

> 但**机制本身是确定成立的**，不依赖这次的测量：
> **注意力权重加起来必须等于 1**（softmax 的性质），
> 所以 token 越多，平均每个分到的越少。
>
> 这就是**上下文腐化**（Context Rot）：窗口还没满，
> 但关键信息已经淹没在无关内容里。
>
> **而这正是实验 2-9（压缩）和 2-7（按需加载）在做的事 ——
> 它们减少的不只是 token 数，更是那个分母。**

## 第 3 步：状态栏在注意力上长什么样（8 分钟）★★

```bash
.venv-attn/bin/python agent.py status_bar
```

复现书里实验 2-7：同一段 Xfinity 轨迹，有/无状态栏，看注意力分布。

### 👀 你会看到

```
  【对照组 A】没有状态栏
     轨迹拿到  28.7%   每字密度 0.256%

  【对照组 B】有状态栏
     轨迹拿到  21.1%   每字密度 0.189%
     状态栏    10.7%   每字密度 0.715%   ← 只有 15 个字

  ★ 状态栏的每字注意力密度是轨迹的 3.8 倍；
    而且加了状态栏之后，轨迹本身拿到的注意力下降了 7.6%。
```

### 💡 学到什么

**书里那句话量化复现了：**

> 对照组 A：注意力高度分散，模型在**从原始信息里做统计**
> 对照组 B：注意力**高度集中在状态栏上**，直接用算好的结论

15 个字的状态栏，每字吸引的注意力是 112 字轨迹的 **3.8 倍**。
而且它**把注意力从原始轨迹上抢走了**（28.7% → 21.1%）。

> **这和[实验 2-8](../2-8-system-hint/README.zh-CN.md)是一对：**
>
> - 2-6 量的是**行为**：0.6B 无状态栏时违规率 50%，有状态栏 32.5%
> - 2-8（本实验）量的是**机制**：注意力从哪儿转移到了哪儿
>
> **两个合起来才完整**：2-6 告诉你「变了」，2-8 告诉你「**为什么**变了」。

## 第 4 步：自己动手改（练习）

### 练习 1 ⭐ 换一层看

改 `LAYERS_FROM_END`（现在是取最后 4 层的平均）。试试只看第 1 层、
只看中间层。

**先猜**：浅层和深层的注意力模式一样吗？

> 一般规律：**浅层更关注位置和句法（相邻 token），深层更关注语义。**
> 你现在有工具可以亲眼验证这句话，而不是背下来。

### 练习 2 ⭐⭐ 看单个头

现在是把 16 个头平均了。改成只看某一个头。

**先猜**：不同的头在关注不同的东西吗？

> 会的，而且差别很大。有的头专门做「看前一个 token」，
> 有的头做「找同类词」。**平均之后这些结构就糊掉了** ——
> 这也是为什么单看平均图容易得出过于笼统的结论。

### 练习 3 ⭐⭐⭐ 把稀释实验的变量拆开

第 2 步那三个效应缠在一起。设计一个能**只测稀释**的做法。

**提示**：把针**固定在离问题 N 个 token 的地方**，只改前面填充的长度。
这样「距离」就不变了。

> 这是本实验最值得做的练习 —— 它教的是**怎么把纠缠的变量拆开**，
> 而这正是实验 2-4 里我踩了三次的那个坑。

### 练习 4 ⭐⭐ 验证汇聚点和内容无关

把句子第一个词换成完全不相干的词（比如「香蕉 的 天气 怎么样」），
看第一个 token 还是不是拿 ~80%。

**先猜**：会变吗？

> 如果不变，就证明了那 80% **确实和语义无关** ——
> 你就亲手验证了「注意力汇聚点」这个概念。

## 附：概念速查

### Q / K / V 一句话

```
Query   当前 token 发出的「我在找什么」
Key     每个候选 token 的「我是什么」
Value   每个候选 token 的「我的内容」

注意力权重 = softmax(Q · K)      ← 你在本实验里看到的那些百分比
输出 = 按权重加权求和所有 Value
```

### 直接看注意力的三个坑

| 坑 | 后果 |
|---|---|
| **不剔除汇聚点** | 第 1 个 token 永远最亮，然后你给它编个解释 |
| **用关键词匹配 token** | 中文分词会把词切开，匹配不到就悄悄算成 0 |
| **比较长度不等的区间** | 长的那段总量必然大 —— 要比**密度**，不是总量 |

**这三个我全踩了。** 详见 SOLUTION。
